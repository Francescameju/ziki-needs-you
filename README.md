# Ziki · Needs You

A prototype for Ziki (HNG15, Week 15): one inbox where agent owners answer only the decisions their agents can't make alone.

**Live:** https://francescameju.github.io/Ziki-needs-you/

- **Decide now:** agent requests sorted by deadline, each with a countdown, the agent's reasoning, the cost of waiting, and one-tap answers.
- **Make it a rule:** turn an answer into a standing rule so the agent asks less next time.
- **Waiting on other people** and **Handled without you:** what's blocked elsewhere, and what the agent did on its own.
- **Agent buddy:** a small robot whose mood follows the queue (nervous near a deadline, happy when answered, asleep when nothing needs you).

Built on Ziki's real mechanisms: typed escalations, 60-second claim offers, the 4-hour owner answer cap, and demotion after silent releases. Colours, fonts and logo come from ziki.dev. Sample data only; nothing is sent to Ziki.
